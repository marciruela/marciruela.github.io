Sobre el proyecto

Cine Montecastelo es una aplicación web completa desarrollada en ASP.NET MVC con C# en Visual Studio. Implementa el patrón MVC con Entity Framework para la gestión de la base de datos SQL Server, incluyendo autenticación de usuarios y panel de administración.

Funcionalidades

  • CRUD completo de películas y sesiones
  • Sistema de reservas con selección de asientos
  • Autenticación y autorización de usuarios
  • Panel de administración completo
  • Entity Framework con SQL Server
  • Patrón MVC con Razor Views
