Sobre el proyecto

Minigranja es una aplicación Java que aplica los principios de la programación orientada a objetos. Implementa herencia, polimorfismo e interfaces para modelar diferentes tipos de animales con sus características y comportamientos específicos.

Funcionalidades

  • Gestión de diferentes tipos de animales
  • Sistema de alimentación y salud
  • Control de producción (leche, huevos, lana)
  • Herencia y polimorfismo aplicados
  • Colecciones ArrayList y HashMap
  • Informes de producción diaria
