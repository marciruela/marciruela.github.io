package modelo;

/**
* Representa un animal de granja como una vaca.
* El animal puede ser alimentado, y al alcanzar cierta
* cantidad de alimento, produce un producto como leche.
*/
public class Animal {

    /** Tipo de animal. */
    private String tipo;

    /** Indica si el animal ha sido alimentado completamente. */
    private boolean alimentado;

    /** Producto que genera el animal. */
    private String producto;

    /** Cantidad máxima de alimento que puede recibir. */
    private final double cantidadMaximaAlimento = 10;

    /**
     * Constructor de la clase Animal.
     * @param producto El producto que genera el animal.
     */
    public Animal(String tipo, String producto) {
        this.tipo = tipo;
        this.producto = producto;
        this.cantidadAlimento = 0;
        this.alimentado = false;
    }

    /**
     * Alimenta al animal incrementando su cantidad
     * de alimento en una unidad.
     */
    public void alimentar() {
        this.cantidadAlimento += 1;
    }
}

Sobre el proyecto

Minigranja modela animales de granja mediante clases con encapsulación completa, documentadas con Javadoc. El controlador gestiona la lógica de alimentación, producción y recolección, separando claramente el modelo de la lógica de control.

Funcionalidades

  • → Gestión de distintos tipos de animales
  • → Sistema de alimentación con límite máximo
  • → Recolección de productos (leche, huevos, etc.)
  • → Control de inventario y base de datos local
  • → Documentación completa con Javadoc
  • → Control de versiones con Git
