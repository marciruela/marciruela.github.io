Models/Animal.cs C# 
using System.ComponentModel.DataAnnotations;

namespace RefugioAnimales.Models
{
    public class Animal
    {
        public int Id { get; set; }

        [Required(ErrorMessage = "El nombre es obligatorio")]
        [StringLength(100)]
        public string Nombre { get; set; } = string.Empty;

        [Required(ErrorMessage = "La especie es obligatoria")]
        public string Especie { get; set; } = string.Empty;

        [Range(0, 30, ErrorMessage = "La edad debe estar entre 0 y 30")]
        public int Edad { get; set; }

        public string Estado { get; set; } = "En adopción";

        // Relación con Adoptante
        public int? AdoptanteId { get; set; }
        public Adoptante? Adoptante { get; set; }

        public DateTime? FechaAdopcion { get; set; }
    }
}

Sobre el proyecto

Refugio de Animales gestiona el ciclo completo de adopción: alta de animales con validación mediante Data Annotations, registro de adoptantes, y el proceso de adopción/desadopción que actualiza la relación entre ambas entidades.

Funcionalidades

  • → CRUD completo de animales y adoptantes
  • → Validación de datos con Data Annotations
  • → Proceso de adopción y desadopción
  • → Almacenamiento de fotos como bytes en BD
  • → Autenticación de usuarios con hash de contraseña
  • → Entity Framework Core con migraciones
