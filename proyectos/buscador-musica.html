Sobre el proyecto

TrackWave es una aplicación web de búsqueda musical que conecta con la API de Deezer para ofrecer resultados en tiempo real. El usuario puede buscar artistas, canciones o álbumes, escuchar previews de 30 segundos y guardar un historial de búsquedas.

Funcionalidades

  • Búsqueda en tiempo real con API de Deezer
  • Reproducción de previews de 30 segundos
  • Historial de búsquedas con localStorage
  • Sistema de recomendaciones
  • Diseño responsive para móvil y escritorio
  • Animaciones y transiciones fluidas
